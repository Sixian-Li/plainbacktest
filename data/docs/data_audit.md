# 购买数据与标准化审计

> 初步审计：2026-08-07；标准化阶段：2026-08-08
> 范围：`data/2026-08-05美股数据_全` 与 `data/2026-08-05多个数据包_rethink`。
> 结论性质：购买数据做过结构抽样；QQQ、VOO、SPY 已完成逐行标准化检查，但不等于其余全市场标的均已验收。

## 1. 结论

两组数据在**结构上可以接入 PyBroker**，但不能原样直接用于正式回测。需要一个数据适配和校验层完成：

- 中文/英文字段统一重命名；
- UTF-8 BOM 清理；
- 日期、代码和 OHLCV 类型转换；
- 每个标的按日期排序、去重和交易日校验；
- 复权口径显式标记；
- 对零价格、异常 OHLC 和不适合交易的记录实施阻断或隔离，禁止静默修补；
- 忽略供应商计算的涨跌幅、振幅和成交额，统一自行重算；
- 每次实验记录来源包、ZIP 校验值、成员文件和数据区间。

目前建议：

1. QQQ 优先使用第二组数据，因其从 1999-03-10 上市日开始，并明确区分“仅拆股调整”和“拆股及股息调整”。
2. VOO 目前只能主要使用第一组数据；其前复权数据可用于第一版连续价格研究，但需要进一步交叉验证复权口径。
3. 第一组后复权日线暂时禁用。
4. 第一版可以使用“拆股及股息调整价格”近似股息再投资总回报，但必须标注这不是“原始成交价 + 现金分红账户流水”的精确回放。
5. 数据中没有独立的现金分红、拆股比例、除权日和支付日事件表，因此暂时不能建立完整公司行动账本。
6. RKLB 使用 Rethink 拆股及股息调整日线，但从 SEC 确认的代码生效日 2021-08-25 才进入标准库；此前 VACQ/SPAC 行情不属于 RKLB 公司历史回测输入。

### 1.1 RKLB 专项验收

- 主源：Rethink Nasdaq-100 成分包的拆股及股息调整 `RKLB.csv`。
- 身份边界：[SEC 8-K](https://www.sec.gov/Archives/edgar/data/1819994/000119312521262190/d175539d8k.htm) 记录合并于 2021-08-25 完成，普通股同日开始以 `RKLB` 在 Nasdaq 交易。
- 标准区间：2021-08-25～2026-08-04，共 1,240 行；与 XNAS 交易日逐日一致，无缺失或额外日期。
- 结构门禁：无坏日期、重复日、缺失值、非正价格或无效 OHLC。
- 双源复核：与全市场供应商 `RKLB_daily_qfq.csv` 在标准区间日期完全一致；收盘价及日收益逐日完全一致。
- 使用限制：两源均非交易所级官方逐笔源；调整后成交量不能用于流动性或成交能力假设。

## 3. PyBroker 字段兼容性

PyBroker 自定义数据源至少需要：

```text
symbol, date, open, high, low, close
```

两组数据都具备这些字段，并且都有 volume。因此适配只是确定性的字段映射：

| 第一组原字段 | 第二组原字段 | 标准字段 |
|---|---|---|
| 日期 | Date | date |
| 代码 | Symbol | symbol |
| 开盘价 | Open | open |
| 最高价 | High | high |
| 最低价 | Low | low |
| 收盘价 | Close | close |
| 成交量 | Volume | volume |

供应商附加字段不直接进入回测核心：

- 第一组的成交额、振幅、涨跌幅、涨跌额、换手率；
- 第二组的 CompanyName、Unadjusted Close、InIndex。

其中 `Unadjusted Close` 和 `InIndex` 可以保留在标准数据的附加列中，供审计和以后研究使用。

第二组比第一组多 463 个交易日，补齐了 QQQ 1999 年上市至 2000 年底的数据。

### 4.2 两组数据并非完全一致

- 在共同日期的大部分近期价格相同，2026-08-04 QQQ 收盘均为 723.85。
- 2002-11-01，第一组记录收盘为 24.55，第二组为 25.25；第二组与当日最高/最低及次日走势更一致。
- 同一时期第一组部分成交量出现约十倍或近百倍差异，例如 2002-10-30 和 2002-11-04。
- 第一组前复权与第二组“拆股及股息调整”在早期价格存在约 6% 差异，抽样共同区间内最大相对差异约 9%。这说明两个供应商的股息/复权方法不能混用。

因此，QQQ 正式研究优先使用第二组；第一组作为交叉检查和增量更新来源，而不是把两个价格序列拼在一起。

### 4.3 第一组后复权异常

第一组后复权 QQQ 和 VOO 均只到 2026-07-28，而其他口径到 2026-08-04。最后一天供应商的涨跌字段出现明显异常：

- QQQ 标示约 +151.62%；
- VOO 标示约 -35.12%。

价格也处在与其他口径不同且没有完成后续更新的尺度上。ZIP 本身没有损坏，这是内容版本/复权计算问题。因此整个第一组后复权日线先禁用，而不是尝试局部修补。

## 5. VOO 抽样结果

第一组 VOO：

- 3,998 行；

2026-08-04 的全市场增量文件：

## 7. ZIP 处理决定

14 个 ZIP 已全部通过 `unzip` 完整性测试。可用磁盘约 675GB，技术上可以全部解压，但当前不建议这么做：

- 全量解压会产生数万小文件；
- 日、周、月和三种复权会产生大量重复数据；
- 当前主要只研究少量标的；
- 原始 ZIP 更适合作为不可变、可校验的数据版本。

采用以下方式：

```text
原始 ZIP 永不修改
  ↓
按实验从 ZIP 直接读取指定 symbol
  ↓
字段标准化与质量校验
  ↓
写入以后建立的 processed/cache 目录
```

因此用户不需要手动解压。后续如果 PyBroker 的读取速度要求缓存，我可以用 Bash 或 Python 按标的选择性解压，而不是展开所有文件。

## 8. 已建立的工具

`backtest/scripts/audit_price_csv.py` 可以读取普通 CSV 或 `archive.zip::member.csv`，检查：

- PyBroker 必要字段；
- 行数、标的数和日期范围；
- 重复 symbol/date；
- 缺失值、坏日期、逆序日期；
- 非正价格和无效 OHLC；
- 最大单日收盘跳变。

它只读取数据，不修改购买的原始文件，并且只使用 Python 标准库。

`backtest/scripts/build_canonical_data.py` 读取 `data/source_registry.yaml`，可以直接读取普通 CSV 或 ZIP member，并生成：

- `data/processed/daily/QQQ.csv`
- `data/processed/daily/VOO.csv`
- `data/processed/daily/SPY.csv`
- `data/processed/manifest.json`
- `data/processed/quality_report.json`
- `data/processed/quality_report.md`

构建器记录原始 member 内容哈希、标准文件哈希、字段映射、复权口径、质量状态和逐行异常。`backtest/tests/data/test_canonical_data.py` 的集成测试已经通过，包括确认 VOO 异常原值没有被静默修正。

### 9.1 供应商交易日历问题

将 QQQ、VOO、SPY 与购买的交易日历逐日比较后，发现日历本身不能作为唯一权威来源：

- 2023、2024、2025 年的 Juneteenth 标记存在错误；
- 2023-06-20 被标为休市，但三个 ETF 均有行情；
- 2025-01-26 是星期日，却被标为交易日；
- VOO 单独缺少 2015-04-09，而 QQQ、SPY 及日历均表明该日开市。

因此，共同缺失的日期不会被误判成三套行情同时损坏；VOO 的 2015-04-09 则保留为独立数据缺口。第二阶段应采用经过测试的交易所日历库，购买日历只作交叉检查。

## Nasdaq-100 历史时点候选审计

2026-08-26 对 `纳斯达克 100 成分股` 原始目录的两个 ZIP 和已解压“拆股及股息调整”目录完成不可变审计。两个 ZIP 均含 480 个 CSV，成员集合、字段、`Date/CompanyName/Symbol`、`InIndex` 和 `Unadjusted Close` 完全一致；已解压 480 个文件与对应 ZIP member 逐字节一致。全部文件均为 UTF-8 BOM + CRLF，没有空文件、坏行、重复日期、非单调日期、非法 OHLC、负成交量、非法 `InIndex` 或重复内容。

两种复权包共有 2,419,555 行，其中 1,490,624 行的复权 OHLC 和 Volume 不同，涉及 273 个文件；这说明复权口径是实质数据选择，不能由文件名替代人工决策。`Unadjusted Close` 可作为收盘成交价审计列，但包内没有完整未复权 OHLC；“拆股及股息调整”Close 只能近似总收益，也缺少独立股息/拆股账本。后续股息还可能回溯改变历史复权比例，正式信号必须冻结来源快照与哈希。

`InIndex=1` 的直接观察范围是 1993-10-01～2026-08-04，直接每日证券数 95～109，连续区间重建后为 96～109。2000-01-03、2010-01-04 为 100，2020-01-02 和 2026-08-04 均为 103。高于 100 可由多股类、Fast Entry、季度再平衡只增不减和分拆证券解释；低于 100，尤其 1993 年起始段，仍需外部人工复核。27 个成员 session 缺少该证券价格，69 个证券有退出后重入，均保留为显式警告而不补值。

对 2020、2021、2024、2025 年年度调整，以及 2026 年 WMT 替换、6 月季度调整和 SPCX Fast Entry 共 7 个生效日，候选数据重建的新增/删除集合与 Nasdaq 官方公告逐项一致。历史退市/剔除文件仍在 480 个独立记录中，因此按成员区间和决策时点滞后使用时，能够避免“只用今天成分股回看历史”的幸存者偏差。它不含历史权重、公告时间或删除原因。

候选输出位于 `data/processed/universes/nasdaq100/pending_review/`，只包含 security master、558 段成员区间、每日数量/缺价摘要、成员变更、来源 manifest 和质量报告，不复制原始价格。AABA、META/FB、BKNG/PCLN 等连续关系不凭字符串推断，带日期后缀的来源证券保持分离，GOOG/GOOGL 保持独立股类。
