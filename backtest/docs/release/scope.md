# 发布范围

本版本从既有 Quant 研究工作区独立整理，目标是让读者拿到代码、项目内 Skill 和本地数据后，能够理解并跑通策略回测流程。

- 复用既有 PyBroker 执行、参考账本、策略、指标、报告模板与测试；新增离线 `quickstart.py` 和只读 `release_data.py` 入口。
- 3 个 Skill 位于根目录 `.agents/skills/`；它们跟随仓库，不指向作者的用户级目录。
- 83 份研究定义及父子谱系保留；历史运行、图表大产物和在线更新档案未复制；5 组 View 关联保留，并链接随包 JSON 元数据。发行版清空 `active_run_id`、`latest_validated_run_id`，并从现有定义重新生成目录。
- 部分定义中的训练 run ID、冻结源哈希和历史研究说明是原研究的溯源。依赖旧训练结果的实验需要恢复对应档案或重新训练；不能因为配置存在就声称全部历史实验可以从零复现。
- 为保留 SPY 训练/测试参数锁定的回归测试，只附带一个小型、明确标注来源的训练指标 fixture。它不是完整历史 run。
- 数据价格、质量证据与两份 Nasdaq ZIP 逐字节复制。其余大原始包、重复解压副本和更新历史不附带。
- 原始包重建及在线更新的源代码保留，相关测试在缺少档案时显式 skip；标准文件结构、哈希、质量状态和策略计算仍进行验证。
- 现有两个 Streamlit 指标/双均线实验台保留为可选工具。

`source_snapshot.json` 记录初始复制时的来源版本、文件哈希和实验旧指针；代码和文档随后为发行版做的适配不宣称与源哈希相同。数据文件仍按该清单核对。

`github_ready_refactor_plan.md` 是源工作区曾讨论的长期工程路线图，不是本版本的发布前置清单。当前不扩展聊天网页、自动化自然语言服务、券商连接或默认在线行情下载。

正式 run 仍要求 Git 版本、干净工作区、数据门禁和完整验证。快速示例采用独立输出目录，只证明此版本的执行和对账链路可用，不绕过原有 `validate_run` 门禁。

项目现名 **PlainBacktest**。快照最初以 `quant-research` 整理，`source_snapshot.json` 中的原始名称与复制哈希作为历史记录保留。
